# 📊 SQL Learning Journey

Welcome to my SQL Learning Repository! 👋

I'm learning SQL step by step to strengthen my database management and data analysis skills. This repository contains my practice queries, concepts, examples, and projects as I progress from the fundamentals to advanced SQL.

## 🎯 Learning Objectives

- Understand SQL fundamentals and database concepts.
- Practice writing efficient SQL queries.
- Learn to retrieve, filter, and manipulate data.
- Work with multiple tables using joins.
- Analyze data using aggregate functions and subqueries.
- Master Common Table Expressions (CTEs) and window functions.
- Apply SQL skills to real-world data analysis projects.

## 📚 Topics Covered

### 1. SQL Fundamentals
- SELECT and DISTINCT
- WHERE and ORDER BY
- LIMIT
- AND, OR, and NOT
- Comparison operators

### 2. Data Manipulation
- INSERT INTO
- UPDATE
- DELETE
- NULL values
- CASE statements

### 3. SQL Functions
- Aggregate functions: COUNT, SUM, AVG, MIN, MAX
- String functions
- Date and time functions
- Numeric functions

### 4. Joins and Relationships
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- FULL OUTER JOIN (where supported)
- Self JOIN

### 5. Intermediate and Advanced SQL
- GROUP BY and HAVING
- Subqueries
- Common Table Expressions (CTEs)
- Window functions
- ROW_NUMBER, RANK, and DENSE_RANK
- Duplicate identification and removal

### 6. Database Concepts
- Primary and foreign keys
- Constraints
- Views
- Indexes
- Stored procedures and triggers
